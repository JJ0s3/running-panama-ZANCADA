# ADR-001 — Identidad de ZANCADA
**Fecha:** 2026-11-03 · **Estado:** Aprobada parcialmente

**Problema:** La demo inicial parece un dashboard genérico y no una marca de running para principiantes.
**Opciones:** verde+lima inicial; azul eléctrico; negro+naranja+blanco hueso; grafito+amarillo.
**Decisión:** conservar paleta Street Pace negro/naranja/blanco hueso; desarrollar motivos propios de pista, trayecto y zancada. Nombre del asistente: Fasty.
**Razón:** marca enérgica y legible; diferencia visual frente a la versión inicial.
**Consecuencias:** actualizar `DESIGN.md`, iconografía, dashboard, onboarding, accesibilidad; no imitar referencias.
**Pendiente:** seleccionar formalmente monograma Z y representación final de Fasty.
